# IT 480 — Deep Learning (Fall 2026)

This repository contains all lab starter materials for IT 480. Each lab has its own folder with everything you need to get started.

## How to Use This Repo

1. **Fork this repository** (click "Fork" in the top-right corner of this page). This creates your own copy under your GitHub account.
2. For each lab, open the relevant folder (e.g., `Lab0/`) and follow the instructions in that folder's `README.md`.
3. Complete your work, commit it back to **your fork**, and submit the requested links on Canvas.

## Working Environment

You can complete labs using either:
- **Google Colab** (recommended, no local setup needed) — open notebooks directly via *File → Open notebook → GitHub*
- **Local VS Code + Jupyter** — clone your fork and install each lab's `requirements.txt`

## Submission Workflow

Every lab and assignment this semester follows the same three-step flow:

1. **Fork** — copy this repo to your own GitHub account (one-time, Day 1)
2. **Edit** — open the relevant notebook in Colab, complete the work, run all cells
3. **Commit & Submit** — save your work back to your fork (Colab: *File → Save a copy in GitHub*), then submit two links on Canvas: your forked repo URL and the direct link to your completed notebook

No files are uploaded directly to Canvas — your GitHub repo is the source of truth for all of your work and its commit history.
